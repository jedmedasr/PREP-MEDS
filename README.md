# PREP-MEDS

PREP-MEDS is a clinical decision-support platform for evidence-linked, auditable pre-endoscopy medication management for elective outpatient EGD and colonoscopy workflows.

This repository is the canonical source for the software architecture, computable clinical rules, evidence provenance, testing artifacts, and product documentation.

> Clinical recommendations are not considered production-approved unless explicitly reviewed and approved through the designated clinical governance process.
